# css-project

Página web de ensayo para practicar HTML y CSS

## Descripción

Este repositorio contiene una página web de ensayo creada con HTML y CSS. El propósito del proyecto es servir como un espacio de aprendizaje práctico donde experimentar con técnicas modernas de CSS y mantener un historial visible del progreso en diseño web.

## Objetivos

- Reforzar y practicar los fundamentos de HTML5 y CSS3.
- Probar layouts modernos (Flexbox y Grid) y técnicas de diseño responsivo.
- Aprender y aplicar variables CSS, tipografías, paletas de color y microinteracciones.
- Crear una página estática accesible y bien estructurada que sirva como portafolio personal de aprendizaje.

## Tecnologías

- HTML5
- CSS3 (Flexbox, Grid, variables, media queries, animaciones y transiciones)
- Recursos estáticos: imágenes y tipografías (locales o desde CDN)

## Estructura del proyecto

- index.html
- css/
  - styles.css

  - (recursos gráficos)
- README.md

## Qué se practica en este proyecto

- Estructura semántica con etiquetas HTML5 (header, nav, main, section, article, footer).
- Maquetación con Flexbox y Grid para componentes y layout principal.
- Diseño responsivo mediante media queries y breakpoints.
- Uso de variables CSS para gestionar paletas, tamaños y espaciados.
- Tipografía, jerarquía visual y escalado responsivo de fuentes.
- Animaciones y transiciones ligeras para microinteracciones.
- Buenas prácticas de accesibilidad: textos alternativos, orden tabulable, roles y contraste.

## Buenas prácticas recomendadas

- Mantener CSS modular y documentado.
- Usar convenciones de nombres claras (p. ej. BEM) para clases.
- Evitar reglas redundantes y favorecer utilidades reutilizables.
- Comprobar contraste de color (p. ej. herramientas como Lighthouse o axe).
- Probar en distintos navegadores y tamaños de pantalla.
